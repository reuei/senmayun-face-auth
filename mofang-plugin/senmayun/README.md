# 森码云实人认证 - 魔方财务插件

## 插件说明

本插件用于将森码云实人认证系统与魔方财务系统对接，实现以下功能：

- 用户支付后自动发起实人认证
- 认证通过后自动开通服务
- 用户中心实人认证入口
- 认证状态查询

## 安装方法

### 方法一：后台安装（推荐）

1. 登录魔方财务管理后台
2. 进入「插件管理」→「安装插件」
3. 上传 `senmayun.zip` 压缩包
4. 点击「安装」
5. 安装完成后点击「启用」

### 方法二：手动安装

1. 将 `senmayun` 文件夹上传到魔方财务的 `plugins/` 目录下
2. 登录管理后台，进入「插件管理」
3. 找到「森码云实人认证」插件，点击「安装」
4. 安装完成后点击「启用」

## 配置说明

1. 进入插件设置页面
2. 填写以下信息：
   - **API地址**：森码云实人认证系统的访问地址（如：https://face.builds.codes）
   - **API Key**：在森码云管理后台创建的API Key
   - **API Secret**：在森码云管理后台创建的API Secret

3. 配置回调地址：
   - 将插件显示的回调地址复制到森码云管理后台的回调地址配置中
   - 回调地址格式：`https://你的域名/index.php?m=senmayun&a=notify`

4. 可选配置：
   - 支付后自动发起认证
   - 下单前必须认证

## 使用方法

### 用户端

1. 用户登录后，在用户中心可以看到「实人认证」入口
2. 点击进入后可以查看认证状态
3. 未认证用户可以点击「开始认证」跳转到森码云认证页面
4. 认证完成后自动跳转回魔方财务

### 管理端

1. 在插件设置中可以配置API参数
2. 在用户管理中可以查看用户的认证状态

## 数据库

插件安装后会自动创建以下数据表：

- `senmayun_face_auth` - 实人认证记录表

## 接口说明

### 发起认证

```
POST /index.php?m=senmayun&a=verify
```

### 认证回调

```
POST /index.php?m=senmayun&a=notify
```

回调参数：
- `token`：认证Token
- `status`：认证状态（passed/failed/expired）
- `score`：相似度
- `liveness_passed`：活体检测结果
- `extra`：额外参数

## 常见问题

### Q: 认证失败怎么办？
A: 用户可以重新发起认证，每人每天最多可以尝试5次。

### Q: 支持哪些认证方式？
A: 支持人脸比对、活体检测、身份证OCR等多种方式。

### Q: 数据安全吗？
A: 所有人脸数据均采用AES-256加密存储，传输全程HTTPS加密。
