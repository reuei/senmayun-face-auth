认证方式

所有 API 请求都需要携带 API Key 进行身份验证。您可以在管理后台创建和管理您的 API Key。

API Key 认证

在请求头中携带 API Key：

// 请求头
Authorization: Bearer YOUR_API_KEY

// 或者在请求体中
{
  "api_key": "YOUR_API_KEY"
}

注意事项

  • • 请妥善保管您的 API Key，不要在客户端代码中暴露
  • • 建议在服务端调用 API，避免 API Key 泄露
  • • 如发现 API Key 泄露，请立即在管理后台重置

错误码

API 返回统一的错误码格式，您可以根据错误码判断请求状态。

错误码 说明 解决方案
200 成功 -
400 请求参数错误 检查请求参数是否完整
401 认证失败 检查 API Key 是否正确
403 权限不足 检查 API Key 权限
404 资源不存在 检查请求地址是否正确
429 请求过于频繁 降低请求频率或联系客服
500 服务器内部错误 稍后重试或联系客服
POST

初始化认证

调用此接口初始化一次认证会话，获取认证 Token。Token 有效期为 5 分钟，使用后立即失效。

接口地址

POST /api/v1/auth/init

请求参数

参数名 类型 必填 说明
api_key string 是 API Key
user_id string 否 用户标识，用于关联您的业务系统
type string 否 认证类型：face(人脸比对) / idcard(身份核验)，默认 face

请求示例

curl -X POST https://your-domain.com/api/v1/auth/init \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "YOUR_API_KEY",
    "user_id": "user_123",
    "type": "face"
  }'

返回示例

{
  "code": 200,
  "message": "初始化成功",
  "data": {
    "token": "a1b2c3d4e5f6.1700000000.signature",
    "expires_in": 300
  }
}
POST

提交认证

提交人脸图片进行认证。支持活体检测、人脸比对等多种认证方式。

接口地址

POST /api/v1/auth/verify

请求参数

参数名 类型 必填 说明
token string 是 初始化获取的认证 Token
image string 是 人脸图片 Base64 编码
image2 string 否 第二张人脸图片（用于1:1比对）
liveness boolean 否 是否开启活体检测，默认 true

返回示例

{
  "code": 200,
  "message": "认证成功",
  "data": {
    "verify_id": "SM202403150001",
    "status": "passed",
    "score": 95.5,
    "liveness_passed": true,
    "channel": "tencent",
    "duration": 480
  }
}

PHP 示例

<?php

class SenmaYunFaceAuth {
  private $apiKey;
  private $apiBase = 'https://your-domain.com/api/v1';

  public function __construct($apiKey) {
    $this->apiKey = $apiKey;
  }

  // 初始化认证
  public function initAuth($userId = '') {
    $data = [
      'api_key' => $this->apiKey,
      'user_id' => $userId
    ];
    return $this->request('POST', '/auth/init', $data);
  }

  // 提交认证
  public function verify($token, $imageBase64) {
    $data = [
      'token' => $token,
      'image' => $imageBase64
    ];
    return $this->request('POST', '/auth/verify', $data);
  }

  // 查询结果
  public function getResult($verifyId) {
    return $this->request('GET', '/auth/result?verify_id=' . $verifyId);
  }

  // HTTP请求
  private function request($method, $path, $data = []) {
    $url = $this->apiBase . $path;
    $ch = curl_init($url);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    if ($method === 'POST') {
      curl_setopt($ch, CURLOPT_POST, true);
      curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    }
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
  }
}

JavaScript 示例

class SenmaYunFaceAuth {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.apiBase = 'https://your-domain.com/api/v1';
  }

  // 初始化认证
  async initAuth(userId = '') {
    const res = await fetch(`${this.apiBase}/auth/init`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        api_key: this.apiKey,
        user_id: userId
      })
    });
    return res.json();
  }

  // 提交认证
  async verify(token, imageBase64) {
    const res = await fetch(`${this.apiBase}/auth/verify`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token, image: imageBase64 })
    });
    return res.json();
  }

  // 查询结果
  async getResult(verifyId) {
    const res = await fetch(`${this.apiBase}/auth/result?verify_id=${verifyId}`);
    return res.json();
  }
}

Python 示例

import requests
import json

class SenmaYunFaceAuth:
  def __init__(self, api_key):
    self.api_key = api_key
    self.api_base = 'https://your-domain.com/api/v1'

  # 初始化认证
  def init_auth(self, user_id=''):
    data = {
      'api_key': self.api_key,
      'user_id': user_id
    }
    res = requests.post(f"{self.api_base}/auth/init", json=data)
    return res.json()

  # 提交认证
  def verify(self, token, image_base64):
    data = {
      'token': token,
      'image': image_base64
    }
    res = requests.post(f"{self.api_base}/auth/verify", json=data)
    return res.json()

  # 查询结果
  def get_result(self, verify_id):
    res = requests.get(f"{self.api_base}/auth/result?verify_id={verify_id}")
    return res.json()
